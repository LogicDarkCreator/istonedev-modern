# ISTONEDEV Lab — Development, Music & Gaming

## Topic
A digital laboratory and knowledge hub covering three creative tech tracks: web engineering (Development), electronic sound production (Music), and game development (Gaming).

## Author
Student, Group 09.02.07, GBPOU KST

## Pages
- `index.html` — Main page (Hero, JS slider, highlights, dynamic material cards, about & FAQ, footer)
- `auth.html` — User registration and sign-in with client-side form validation
- `cabinet.html` — Protected personal dashboard displaying user info and saved favorites

## Features Implemented
- Semantic HTML5 structure and unified design tokens using CSS custom properties (`:root`);
- Responsive layout built with CSS Grid and Flexbox (desktop, tablet, mobile + burger menu);
- Interactive JavaScript slider with autoplay, pause-on-hover, arrow controls, and dot indicators;
- Dynamic rendering of 8 material cards from a JS array (`map` + `join`), category filtering, and live search;
- Full-screen details modal for each card;
- Client-side registration, login, logout, and persistent favorites stored in `localStorage`;
- Route protection restricting dashboard access to authenticated users only.

## How to Run
Open `index.html` in any modern web browser.
